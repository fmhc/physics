# VORTEX-MATCH-1 – Modellzuordnung vor Simulation

Status [H]: neuer analytischer Prüfauftrag. Quelle und Grenzen: [Volltextvergleich, Abschnitt 2](../VOLLTEXT-VERGLEICH-20261007.md#2-fraktionale-wirbel-interessante-alternative-mit-zusätzlichen-annahmen).

Erstelle eine Tabelle mit beiden Seiten: Feldinhalt, globale/lokale Symmetrien, Vakuummannigfaltigkeit, chemisches Potential, Flavourzahl, Ladungsdefinition und Randbedingungen. Jede fehlende Entsprechung wird als neue Annahme geführt.

Danach für eine **konkrete** minimale Wirkung Vakuum und zulässige Windungssektoren analytisch bestimmen. Erklären, welches Objekt eine Quelle oder ein Ende des Wirbels sein kann und ob ein isolierter Wirbel endliche Energie besitzt. Endliche Box und thermodynamischer Grenzfall trennen.

Entscheidung: Gibt es eine wohldefinierte neue Modellvariante mit mindestens einer unterscheidbaren Vorhersage gegenüber bisherigen Wirbelansätzen? Wenn nein, Literaturkandidat zurückstellen. Wenn ja, erst dann einen getrennten numerischen Test entwerfen. Baryonphasenwindung wird nicht als elektrische Ladung bezeichnet; ein Wirbel wird nicht ohne Quantenzahlen als Quark bezeichnet.
