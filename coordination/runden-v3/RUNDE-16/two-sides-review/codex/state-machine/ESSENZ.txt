Die Nutzerformulierung status+status=change wird als lokale Uebergangsfunktion
R:(s_i,s_j,c_ij)->(s'_i,s'_j,c'_ij) praezisiert. Das Plus ist keine numerische
Addition, sondern Begegnung/Wechselwirkung. Die Kante c kann ein unterwegs
befindliches Signal speichern. Ohne freigegebene Wechselwirkung keine
Zustandsaenderung. Regel, Zustand und Ausloeser sind drei verschiedene Dinge.

Ein Ereignis e_k erzeugt die Voraussetzung fuer e_(k+1). Dies definiert zuerst
eine Kausalordnung, nicht eine fundamentale Zeitdauer. Mehrere unabhaengige
Ereignisse bilden eine partielle Ordnung. Disjunkte lokale Regeln koennen
kommutieren; um dieselbe Ressource konkurrierende muessen durch Physik oder
eine ausdrueckliche Arbitrierungsregel entschieden werden. Eine globale
Update-Schleife ist kein Nachweis einer universellen Synchronuhr.

KONKRETER MOTORAEHNLICHER ANKER
Ein Token trifft auf einen Knoten mit lokalem Rotor r_i. Er schaltet r_i
modulo AnzahlPorts weiter und wird durch den gewaehlten Port abgegeben.
Alle anderen Rotoren bleiben unveraendert. So gibt es lokale Speicherung,
Umschalten, Weitergabe und Rueckkehr, ohne vorausgesetzten globalen4Takt.
Portreihenfolge und Starttoken bleiben Modellannahmen. Anfangsruhe ohne
Token bleibt perDefinitionRuhe; die Maschine erklaert keine Erstanregung.
Die Regel ist bekannt: Rotorrouter, kein eigener neuer Grundmechanismus.
Primaertext: Holroyd/Levine/Meszaros/Peres/Propp/Wilson, arXiv0801.3306,
https://lionellevine.github.io/sand.pdf, §4 Lemma4.9 einschliesslichBeweis,
PDF-Seiten25-26 gelesen. Im Eulerischen rekurrenten Zustand wird jede
gerichteteKante proUmlauf einmal besucht. Numerik ist Kontrolle diesesSatzes.

PHYSIKBRUECKE, DIE NOCH FEHLT
Ein12Ereigniszyklus hat mit positiven Laufzeiten tau_e die Dauer Summe tau_e.
DieseZeiten muessen aus einem kontinuierlichenModell, Barrieren oder
Signalgeschwindigkeiten folgen, nicht aus dem Zaehler selbst. Ein Zyklus
beweist weder Energieerhaltung noch nutzbare Arbeit. Verlustfreiheit und
vorhandeneAnregung koennen Bewegung erlauben; dauernder Arbeitsentzug
braucht eine Energiebilanz. Vollstaendige Reversibilitaet getrennt pruefen:
Der Rotorrouter kann vor seinem periodischenTeil Zustandsinformation verlieren.
Eine konservative Physikinterpretation braeuchte zusaetzliche verborgene
Variablen oder eine andere reversibleRegel, samt definierterEnergie.
